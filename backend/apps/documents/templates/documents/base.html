{% comment %} The frame every generated document sits in. Two things to know before editing: 1. Comments here MUST be {% comment %} tags, never {# … #}. Django's hash comment is single-line only — a multi-line one is not a comment at all, it is literal text, and six of them were being printed at the top of every document that this system has issued. 2. The renderer (xhtml2pdf) computes column widths up front and cannot cope with a table nested inside a table cell: it ends up with a negative available width and produces no page at all. One level of table is safe. Do not nest. The pharmacy issues the document, so the pharmacy's identity leads it. This used to head every page "PharmaCore by Medlink" — the name of the software, which is not a party to anything the document says. The generator signs the footer instead, where it belongs. {% endcomment %} {{ doc_number }} {% comment %} One table, two columns: who issued this on the left, what it is on the right.
