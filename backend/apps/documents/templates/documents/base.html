{% comment %} The frame every generated document sits in. Two things to know before editing: 1. Comments here MUST be {% comment %} tags, never {# … #}. Django's hash comment is single-line only — a multi-line one is not a comment at all, it is literal text, and six of them were being printed at the top of every document that this system has issued. 2. The renderer (xhtml2pdf) computes column widths up front and cannot cope with a table nested inside a table cell: it ends up with a negative available width and produces no page at all. One level of table is safe. Do not nest. The pharmacy issues the document, so the pharmacy's identity leads it. This used to head every page "PharmaCore by Medlink" — the name of the software, which is not a party to anything the document says. The generator signs the footer instead, where it belongs. {% endcomment %} {{ doc_number }} {% comment %} The footer lives in a repeating frame, not in the flow. In the flow it cost about 70pt and this renderer keeps its table together, so a document that nearly filled the page pushed the whole block — contact, issuer, QR — onto a second sheet by itself. Whether that happened depended on how long the pharmacy's address happened to be, which is not a thing a document's page count should turn on. In a frame it takes no flow height at all and appears at the bottom of every sheet, which is what a printed commercial form does anyway. {% endcomment %}
